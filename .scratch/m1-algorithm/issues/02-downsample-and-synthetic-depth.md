# 02: 降採樣和合成深度

Status: ready-for-agent

**What to build:** 不用 Gazebo 也能產生深度幀：給一個場景（可傾斜的地面、長方體凸起、長方形直壁坑）和相機姿態，射線投射出 640×480 的 z-depth，加雜訊，再用橋接程式也會用的同一個降採樣函式變成 160×120 公釐。M2 的回放程式會沿用。

**Seams:** 降採樣

- [ ] 降採樣照 dev_board_spec §2：無效檢查、有效少於一半輸出 0、取第 `n/2` 個；縮小倍數由輸入輸出的大小決定
- [ ] 單元測試：inf、−inf、NaN、−1 m、0.05 m、25 m、70 m → 0；5 m → 5000；8 個 3 m＋8 個 13 m → 13000；只有 7 個有效 → 0；640×480 → 320×240 也對
- [ ] 降採樣不依賴設定檔物件，可以單獨連結
- [ ] 合成深度是獨立的函式庫，開發板主程式不連結它
- [ ] 支援 roll、pitch、yaw、`t_cam`、固定 stddev 的高斯雜訊（加在 640×480 上）、亂數種子、指定區域的像素改成 0
- [ ] 像素中心在 u+0.5、v+0.5
- [ ] 用已知答案檢查：正下方深度、已知像素的落點、傾斜和 `t_cam` 下的落點、坑底和坑壁、凸起的頂面和側面、超過 far 是 0；同一個種子結果相同
- [ ] README 的目錄更新
- [ ] `pc-debug`、`pc-release`、`h1v1`＋qemu 測試通過
