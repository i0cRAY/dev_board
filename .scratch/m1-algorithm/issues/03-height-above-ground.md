# 03: 離地高度

Status: ready-for-agent
Blocked by: 02

**What to build:** 判斷核心的第一條完整路徑：餵姿態、位置、深度幀和「現在」，每一個能用的幀回傳 `agl` 和資料狀態。M2 接上去就能送 `height` 訊息。介面照 [M1 spec](../spec.md)「模組」一節。

**Seams:** 判斷核心

- [ ] 核心不開執行緒、不讀時鐘、不碰網路；所有事件都帶「現在」；從 `Config` 建立
- [ ] 姿態、位置照幀的 sim time 內插（線性；yaw 走最短角度），緩衝 1 秒
- [ ] 前處理照 dev_board_spec §5 第 3～7 步，反投影用 `u+0.5`、`v+0.5`；射線沒有往下打到地面的無效像素忽略；整幀無效不會當掉
- [ ] `agl` 照 §6.1，偶數個時取中間兩個的平均；正下方有高度的細格不到一半時是空的
- [ ] 平地 1.5、3、7.5、12、18 m：`agl` 跟真值一致；25 m：空的
- [ ] roll、pitch 到 6° 仍有 `agl`，是垂直距離；`t_cam` 有前後左右偏移時仍量機身中心正下方
- [ ] 屋頂上空、坑底上空的 `agl` 是到正下方的距離
- [ ] 沒收過深度 → 狀態 `no_depth`；沒收過姿態或位置 → `no_px4`；都沒有 → `no_depth`
- [ ] 幀時間和姿態時間剛好夾住、剛好相等都能用；完整的逾時、等待、倒退規則留給 08
- [ ] `pc-debug`、`pc-release`、`h1v1`＋qemu 測試通過

## Comments

2026-11-26（使用者決定）：03 的前處理只做 `agl` 用得到的部分：§5 第 3～5 步，第 6 步只累加每格的有效點數和高度總和；整幀無效不會當掉。Moments 其他項、`h20`、2D 前綴和、第 7 步的無效像素落點留到 04，跟 `evaluate` 的測試一起寫。原因：03 唯一的輸出是 `agl`，其他部分在 03 看不到也測不到（spec 規定只測外部行為），先寫等於沒有測試的程式。
